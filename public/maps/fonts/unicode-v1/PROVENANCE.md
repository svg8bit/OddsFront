# OddsFront Unicode map glyphs

Generated by `scripts/generate-localized-map-assets.mjs` using TinySDF and PBF.
Latin, Cyrillic, Arabic and Hebrew: DejaVu Sans, system font with its original
license retained in DejaVu-LICENSE.txt. CJK and Hangul: Noto Sans CJK SC Regular,
SIL Open Font License 1.1, retained in Noto-CJK-LICENSE.txt.
Source: https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese
The compiled glyph ranges are gzip compressed; only ranges needed by visible
labels are downloaded. No runtime font rasterization is required.
